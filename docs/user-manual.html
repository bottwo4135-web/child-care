User Manual

Audience: Staff, Admin, and Parents. This manual provides step-by-step instructions for common tasks.

Getting Started

  1. Open the app (public/index.html or hosted URL).
  2. Sign in with your email and password.
  3. If you do not have an account, ask an Admin/Staff to create one.

Staff Tasks

Record Attendance

  1. Go to Staff Dashboard → Attendance tab.
  2. Enter Child ID, Staff ID, select Check In/Out, click Save.
  3. Confirmation appears; parents get a notification in their portal.

Log Health Incident

  1. Dashboard → Health tab.
  2. Enter Child ID, type (e.g., Fever), optional temperature and notes.
  3. Click Log Incident.

Add Schedule Entry

  1. Dashboard → Schedule tab.
  2. Enter the date, group (e.g., Toddlers), title (Nap time), times, notes.
  3. Click Add.

Create Invoice

  1. Dashboard → Billing tab.
  2. Enter Parent ID, Child ID, a line item, quantity, and unit price.
  3. Click Create Invoice. The invoice is created in Draft status.

Parent Tasks

View Updates

  1. Log in and you will be redirected to Parent Portal.
  2. The Real-time Updates section shows attendance and health notifications.

Accessibility Tips

  • Use a modern browser for best support.
  • All buttons are large and keyboard accessible (use Tab/Shift+Tab).

Troubleshooting

  • Can’t sign in: Verify Firebase config is set in app/firebase-config.js.
  • Permissions error: Ensure your account role is correct (staff/parent/admin).
  • No notifications: Ensure you are on HTTPS and accepted notification permissions (future FCM support).
