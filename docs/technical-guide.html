Technical Guide

Architecture: Client-side app (HTML/CSS/JS) with Firebase (Auth, Firestore, Hosting, optional Messaging). OOAD with UML guides the structure.

Project Structure

See README for full tree and module responsibilities.

Firebase Setup

  1. Create a Firebase project; enable Auth (Email/Password), Firestore, Hosting, Messaging.
  2. Copy Web App config to public/app/firebase-config.js.
  3. Deploy firestore.rules: firebase deploy --only firestore:rules
  4. Deploy hosting: firebase deploy --only hosting

Security Rules

See firestore.rules for least-privilege access enforcement.

UML

UML diagrams (use case, class, sequence, activity) are described in README and should be exported as images into docs/uml/ for submission. Mermaid code is provided in README.

Extending the System

  • Replace the messages feed with FCM Web Push and/or Cloud Functions for real notifications.
  • Add QR scanner via Html5Qrcode or QuaggaJS; encode childId in QR.
  • Add role management UI and admin capabilities.
  • Replace IDs with Firestore-generated docs and proper references.
  • Add analytics and audit logs.

Performance and Scale

  • Use indexed queries for attendance by childId, order by timestamp desc.
  • Use pagination for list views.

Accessibility

  • Keyboard navigation, color contrast, and large touch targets are implemented in styles.css.
